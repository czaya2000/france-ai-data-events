10. **Third-party listings.** Brief IA, allai.events and Meetup city pages: facts only (title, date, time, city, venue, url). Descriptions are never stored. Blurbs are generated by the LLM step from the basic facts. Eventbrite: slow, cached, exponential backoff, turned off for the run on 429/405, never bypassed.
11. **Self-expanding discovery with caps.** New Meetup groups and Luma calendars found in any source are checked and, if they work, polled daily; trust `noisy` until the owner promotes them. Caps per run (see `pipeline/prepare.mjs` and `config/country.mjs`) keep run time and request counts bounded.

The secret `CLAUDE_CODE_OAUTH_TOKEN` is not set yet: the workflow tests for it and skips the step with a `::notice::`, leaving candidates deferred.
